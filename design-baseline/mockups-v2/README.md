# Bản thử giao diện v2 (tham chiếu) `[VÍ DỤ]`

Năm tệp HTML tự chứa đã được người dùng duyệt trên Tapetco ERP (08–09/10/2026), chép nguyên để **nhìn** cách làm v2. Màu, logo, nội dung là của Tapetco: không áp nguyên văn, chỉ lấy cách bố cục và hành vi. Khi bản thử và `../principles.md` khác nhau thì quy tắc thắng.

| Tệp | Nội dung |
|---|---|
| `danh-sach-v2.html` | Danh sách v2: thẻ danh sách, ô tìm mọi cột, hàng ô lọc thu gọn, ⋮ và chuột phải, phân trang, danh mục nhập thẳng, thẻ điện thoại |
| `bieu-mau-v2.html` | Biểu mẫu v2: thanh đầu dính, dải Tình trạng, nhóm thu gọn, dòng hàng theo danh sách v2, hộp thoại không khung viền quanh trường |
| `dashboard-v2.html` | Trang chủ v2: KPI cạnh lời chào, biểu đồ theo phân hệ |
| `trang-chu-v21.html` | Trang chủ v2.1: thanh trạng thái có mũi tên chú giải, biểu đồ giá trị, thường dùng nhiều hàng, Bảng tin |
| `dang-nhap-v2.html` | Đăng nhập v2: thẻ lớn, hình isometric (ngày/đêm), hộp tài khoản demo |

Mở trực tiếp bằng trình duyệt (cần mạng để tải font Inter; không có mạng thì dùng font hệ thống).
