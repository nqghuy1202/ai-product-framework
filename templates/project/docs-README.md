# Tài liệu dự án

| Thư mục | Nội dung | Skill tạo ra |
|---|---|---|
| `product/` | PRD, tính năng tách nhỏ | `/apf:prd` |
| `architecture/` | Kiến trúc, ADR | `/apf:architecture` |
| `ux/` | DESIGN.md, EXPERIENCE.md, bản thử giao diện | `/apf:ux` |
| `stories/` | Epic, story, BOARD.md, DEFERRED.md | `/apf:stories`, `/apf:build` |
| `app-map/` | Tài liệu từng vùng code, có `covers` (khi bật) | các skill, khi đổi code |
| `ops/` | Runbook và các sổ vận hành (khi bật) | `/apf:ops` |
| `security/` | Các bản review bảo mật (khi bật) | `/apf:security` |
| `_generated/` | Máy sinh, không sửa tay | `apf docs --write`, `apf board --write` |
